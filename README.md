An offline / air-gapped AI system built for Network Operations Center (NOC) environments — designed to run entirely without internet access on secure enterprise networks.

**Tech Stack:**
<img src="https://skillicons.dev/icons?i=python" height="26"/> <img src="https://skillicons.dev/icons?i=flask" height="26"/> <img src="https://api.iconify.design/simple-icons/ollama.svg?color=%234CD3FF" height="26"/> <img src="https://api.iconify.design/simple-icons/langchain.svg?color=%234CD3FF" height="26" onerror="this.src='https://api.iconify.design/mdi/link-variant.svg?color=%234CD3FF'"/>

**Pipeline:**

```text
Network Logs
     ↓
Data Processing
     ↓
Anomaly Detection  (Random Forest + Isolation Forest)
     ↓
RAG Pipeline
     ↓
ChromaDB
     ↓
LangChain
     ↓
Local Qwen 2.5 LLM
     ↓
Ollama
     ↓
NOC-AI Assistant
```

**Key Features**
- 🦙 Local LLM inference via Ollama (Qwen 2.5) — fully offline
- 🔒 Air-gapped architecture for secure network environments
- 🔗 RAG over technical documentation with ChromaDB
- 🚨 Network log anomaly detection (Random Forest + Isolation Forest)
